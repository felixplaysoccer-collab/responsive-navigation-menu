
# Responsive Navigation Menu

A responsive navigation menu developed using HTML,
CSS, and JavaScript for my INFOST 320 Web Design II
course at the University of Wisconsin-Milwaukee.

## Project Features
- Responsive navigation menu
- Mobile-friendly hamburger menu
- JavaScript toggle functionality
- CSS media queries with a 650px breakpoint
- Custom navigation colors
- Accessible text and background contrast

## Technologies Used
- HTML5
- CSS3
- JavaScript

This project helped me practice responsive web
design, JavaScript interactions, CSS media queries,
